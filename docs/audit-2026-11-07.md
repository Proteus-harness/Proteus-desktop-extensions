## Production SDK и Git

| ID | Изменение и регрессия |
|---|---|
| EXT01 | Дедупликация доставки общей session projection исправляется у producer в Desktop; одинаковые delta нельзя сравнивать по payload. Wire не меняется. |
| EXT02 | Входящая очередь SDK: 128 сообщений / 32 МиБ исходного JSON, permit жив до окончания handler. Reader ограничивает кадр 16 МиБ, один кадр может ожидать допуска. Медленный consumer сохраняет backpressure и порядок. Неподтверждённые `set_session` всех активных и parked sessions делят 128 запросов / 1 МиБ; отказ происходит до отправки. Тесты лимитов, освобождения, порядка и нескольких сессий. |
| EXT03 | «Все изменения»: 40 файлов и 4 МиБ encoded patch/metadata, с учётом escaping и UTF-8, с явным частичным результатом. Тест больших индивидуально допустимых patches проверяет готовый JSON frame, а не только исходную строку. |
| EXT04 | Отдельный working-diff LRU 16 записей / 8 МиБ; per-path revision invalidation сохранена. Тесты удержания, eviction, повторного HTTP и независимости immutable history. |

Python mirror схемы обновлён для rich-text inlines, picker navigation/search,
stack transition и SVG baseline/em-size; authoritative схема остаётся Desktop.

подтверждёнными дефектами; снятые гипотезы C4 zero-row/usecase collision и
исторический metric baseline не превращаются в новые findings.
