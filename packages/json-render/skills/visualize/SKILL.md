name: visualize
description: Представляй сравнения, метрики, таблицы, графики и схемы в ответах Proteus нативными json-render или SVG блоками, когда визуальная форма облегчает понимание.
---

Используй визуализацию, когда она помогает сравнить варианты, увидеть структуру
или соотношение величин. Обычный короткий ответ оставляй текстом. Используй
данные пользователя; вымышленные числа явно называй примером.

Для нативных таблиц, метрик и графиков верни завершённый Markdown fence
`json-render`, содержащий один корректный JSON-объект. Для схемы или произвольной
иллюстрации из векторных фигур используй завершённый fence `svg`.
Краткое объяснение результата оставь обычным текстом рядом с блоком.

Каталог `json-render` закрыт; имена `type` только в `snake_case`:

- `stack`: `children`, необязательные `direction` (`column` или `row`), `gap`
  (`none`, `small`, `medium`, `large`).
- `card`: необязательные `title`, `children`.
- `text`: `text`, необязательные `size` (`small`, `normal`, `large`), `tone`,
  `single_line`, `mono`. По умолчанию текст переносится.
- `metric`: строки `label`, `value`, необязательные `detail`, `tone`.
- `table`: строки `columns`, массивы строк `rows`; число ячеек равно числу колонок.
- `bar_chart`: `bars` из `{label, value, tone?}`, необязательный `unit`.
  `value` — конечное неотрицательное число.
- `tabs`: `tabs` из `{label, count?, children?}`. Переключение локальное,
  action не нужен. `count` — неотрицательное целое.
- `svg`: строка `source`, числа `width`, `height` в диапазоне 1…4096.

`children` — массив объектов из этого каталога. `tone`: `default`, `muted`,
`accent`, `success`, `warning`, `danger` или `#rrggbb`; предпочитай смысловые
имена. Все надписи и ячейки — строки, даже если показывают число.
Пример с синтетическими данными:

```json-render
{"type":"card","title":"Пример сравнения","children":[{"type":"metric","label":"Готово","value":"12","tone":"success"},{"type":"bar_chart","unit":"мин","bars":[{"label":"Первый вариант","value":8},{"label":"Второй вариант","value":5,"tone":"accent"}]}]}
```

Для SVG задай `xmlns="http://www.w3.org/2000/svg"` и `viewBox`; передавай
самодостаточные фигуры, пути, текст и цвета. Область отдельного SVG fence —
640×360; другой размер задавай через `svg` в `json-render`. Ссылки допускаются
только на локальные `#fragment`, например градиент из собственного `defs`.
Не используй внешние изображения, файлы, шрифты, HTML, `foreignObject`, JS.

Не придумывай типы, поля или обработчики. В этом каталоге нет кнопок, форм,
tool calls, URL-полей, произвольных actions и кода. Не вставляй комментарии,
многоточия, незавершённые JSON-строки или Markdown внутрь JSON. Один блок —
не больше 256 КиБ, 24 уровней и 2000 виджетов; большие наборы сначала агрегируй.
Если запрошенное представление не выражается каталогом, выбери SVG или текст.
