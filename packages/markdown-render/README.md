# Markdown

Процессное расширение для `text/markdown` и fenced-языков `md`/`markdown`.
Разбор GFM, выбор завершённых fenced-блоков и преобразование абзацев в HTML
живут в этом пакете. Клиент использует только общие нативные примитивы
`rich_text`, `code` и `content`; WebView не создаётся.

Завершённый верхнеуровневый блок языка, включённого в
`content.context.languages`, становится дочерней визуализацией. Например,
`mermaid` и `json-render` обслуживаются самостоятельными пакетами. Незакрытый
или неизвестный fenced-блок остаётся readonly кодом с подсветкой и копированием.
Fenced-примеры `md` и `markdown` внутри Markdown всегда показывают буквальный
исходник. Пакет не визуализирует их рекурсивно: в учебном примере «пишешь →
получаешь» исходник и отдельно написанный результат сохраняют разный смысл.
Вложенные Mermaid/LaTeX внутри такого примера также остаются кодом. Обычные
Markdown-документы, файлы и unfenced-таблицы продолжают отображаться полностью.
Верхнеуровневые display-формулы между отдельными строками `$$` разбираются
тем же markdown-rs и направляются зарегистрированному языку `latex` (либо
`tex`) в общей рамке кода с исходником и копированием. Без такого расширения
показывается исходник формулы. Незакрытая формула остаётся текстом до получения
закрывающей строки. Строчные формулы `$E=mc^2$` распознаёт тот же markdown-rs,
в том числе внутри начертаний, списков, цитат и ячеек таблицы. Они передаются
`latex`/`tex` через общие inline-слоты `rich_text` и не создают отдельной рамки
блока. Исходные доллары остаются выделяемым fallback при отключённом поставщике
или ошибке формулы. Код, экранированные и незакрытые доллары, а также суммы вида
`$100 and $20` остаются текстом. Пробелы у границ `$ x$` / `$x $`, переносы строки
внутри формулы и завершающий доллар перед цифрой не принимаются. Alt-текст
картинок не создаёт inline-поверхности. На один rich_text допускаются до 256
формул по 32 КиБ, остальные остаются буквальным текстом. Display-математика
внутри списков и цитат пока остаётся текстом.
Оригинальные байты вложенного источника, включая CRLF и Unicode, сохраняются.
Стабильные ordinal ids сохраняют дочерний view при дописывании ответа.

Нативный HTML поддерживает заголовки, абзацы, начертания, ссылки, списки и
таблицы. Tasklist сохраняет семантические disabled HTML checkbox для общих
нативных элементов списка клиента; символы `☐`/`☑` не подставляются.
Код внутри цитат и вложенных списков остаётся форматированным HTML текстом:
там нет отдельной подсветки/кнопки кода. Верхнеуровневые блоки используют
общий readonly editor, растущий по физическим строкам без вертикальной
внутренней прокрутки. Горизонтальная прокрутка длинных строк остаётся нативной.

Пакет не запускает дочерних процессов. Кеш преобразования хранится только для
открытых content views и освобождается при `close`. Неизменные завершённые
абзацы не конвертируются повторно при дописывании хвоста. Reference links
используют общую таблицу определений всего документа, в том числе через
fenced-блоки. Добавление или изменение определения обновляет сохранённые
абзацы со ссылками; неизменный код повторно не разбирается.

Проверка: `cargo test --locked -p extension-markdown-render`.
