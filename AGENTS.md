# Работа С Proteus-desktop-extensions

Поставляемые по умолчанию процессные расширения приложения Proteus.
Автор набора — Proteus Project. Формат и границы описаны в PROTOCOL.md.
Документация — на русском языке.

packages/<id> содержит поведение и манифест; sdk — общий stdlib Python SDK.
package.py копирует SDK и LICENSE в каждый самостоятельный ZIP или portable
пакет. Не дублируйте SDK вручную и не добавляйте сторонние зависимости без
конкретной необходимости. Включённое по умолчанию расширение использует тот
же контракт, что и установленное пользователем.

Не переносите поведение конкретного пакета в GPUI-клиент и не вводите ветки по
id. Для нового нативного виджета измените публичную схему клиента и все
потребители вместе. Черновой протокол не требует legacy aliases.
При смене сессии отбрасывайте устаревшие ответы, сохраняйте action sequence,
фокус, клавиатуру и отсутствие повторной передачи текста по каждому delta.
Не записывайте токены сервера или содержимое реальных сессий в логи.

Проверки: `python3 -m unittest discover -s tests -p 'test_*.py'`.
При изменении общего контракта — ещё `python3 scripts/test.py` и живое окно
в Proteus-desktop (соседний ../Proteus-desktop). Тесты используют синтетические данные
и loopback HTTP. После успешной проверки создайте commit и пересоберите
portable клиента: `python3 scripts/portable.py --fast`.
