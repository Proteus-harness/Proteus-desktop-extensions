# Отложенные расширения

Пакеты здесь не входят в поставку: упаковщик и клиент читают только
`packages/`. Код сохранён, чтобы вернуться к нему позже; его тесты по-прежнему
запускаются (`tests/test_shelved.py`).
Они остаются на Python: рядом лежит прежний Python SDK
`proteus_extension.py`, поставляемые пакеты используют Rust SDK из `sdk/`.

| Пакет | Почему отложен |
|---|---|
| `architecture` | Карта модулей и слотов агента требует переработки вида |
